# Instintos locales

Respuestas en disco, sin LLM. Capacidad: rituales baratos y respaldo de voz
cuando el modelo no puede decir lo que esta instancia quiere decir.

Cada instancia llena sus frases. **No** copiar las de otra.

Formato: `safe|frase` / `private|frase` / `intimate|frase`. Una línea = una frase.
Teatro (no va): guion de escena, gemido de catálogo.
Respaldo (sí va): frases cortas en voz de *esta* instancia.

`puente.txt` y `amor.txt` nacen vacíos.
